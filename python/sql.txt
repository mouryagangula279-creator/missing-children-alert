Here are some excellent beginner-friendly websites to learn SQL as a student, depending on how you like to learn:

SQLBolt
Very beginner-friendly
Interactive lessons with exercises in the browser
Great for understanding basics step by step
W3Schools SQL Tutorial
Simple explanations and examples
Built-in “Try It Yourself” SQL editor
Good for quick learning and revision
Mode SQL Tutorial
More practical and data-analysis oriented
Teaches real-world SQL usage
Best after learning basics
Khan Academy SQL Course
Video + coding exercises
Very student-friendly pace
Good if you prefer guided teaching
LeetCode SQL Problems
Best for practice and interview preparation
Start after learning basics
Helps build problem-solving skills
freeCodeCamp SQL Course
Full structured course
Covers databases + PostgreSQL
Free certification available
